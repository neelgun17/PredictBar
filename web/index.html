Features

Everything you watch, in the menu bar.

No browser tab, no refresh. PredictBar keeps your positions live where you already are.

Live menu-bar metric

Show cash-out value, ROI, P&L, portfolio value, or balance — click to cycle between them anytime.

Per-position detail

Current price, average entry, quantity, P&L and ROI for every open position — commission included.

One-click sell & hedge

Shortcuts that deep-link straight to Kalshi so you can act on a position the moment it moves.

Smart alerts

ROI thresholds, profit and price targets, stop-loss, and arbitrage detection — with hysteresis so you don't get spammed.

Real-time prices

Quotes stream over a live WebSocket connection, so the numbers update the instant the market does.

Private by design

Credentials live in the macOS Keychain, and all API traffic to Kalshi is certificate-pinned over HTTPS.

Smart alerts

Get pinged only when it matters.

Set thresholds globally or per position. State-based triggers with a buffer mean one clean notification, not a flood.

Select a type to preview its notification.

Install

Up and running in under a minute.

Homebrew is the quickest path. Prefer a download? Grab the DMG from GitHub Releases.

  1. 1

    Install the cask

  2. 2

    Clear the quarantine flag once

    The app is ad-hoc signed (not notarized), so macOS blocks the first launch.

  3. 3

    Launch it

  1. 1

    Download the latest DMG

    Grab PredictBar-vX.X.X.dmg from the Releases page, open it, and drag PredictBar into Applications.

    Open GitHub Releases →
  2. 2

    First launch: right-click → Open

    Because the build is ad-hoc signed, macOS shows an “unidentified developer” notice the first time. Right-click PredictBar → Open → Open. Required only once per install.

🔑

One-time Keychain prompt. The first time PredictBar reads your saved API credentials, macOS asks for Keychain access. Click Always Allow (not “Allow”) so it doesn't ask again.
